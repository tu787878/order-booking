# TCG Restaurant Shop installation

1. In WordPress, open **Plugins → Installieren → Plugin hochladen** and upload this ZIP.
2. Activate **TCG Restaurant Shop**.
3. Configure the shop under **Produkte → Einstellungen**.
4. If updates require private access, open **Produkte → Update-Zugang** and enter the update-access token.

The technician may complete step 4 while setting up the customer's WordPress site. Otherwise, the customer can enter their own token later. The token is stored only in that WordPress installation; it is not included in this ZIP and is never shown again in the admin interface.
